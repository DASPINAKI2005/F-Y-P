Security & trust

Repository access

Public GitHub repositories are validated and downloaded via the backend using the GitHub REST API. The app never executes repository code or package installers.

Static analysis

Archives are scanned locally in a deterministic workspace. Unsafe paths, secrets, and oversized content are filtered before AI review.

AI processing

Evidence is sent to configured AI providers in a provider-priority sequence. Keys remain in backend environment settings and are never exposed to the browser.

Evidence generation

Focused analyses cite real file excerpts and line ranges extracted from the repository workspace after ranking and review.
